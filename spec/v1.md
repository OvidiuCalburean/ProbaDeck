# ProbaDeck language-independent specification v1

The key words **MUST**, **MUST NOT**, **SHOULD**, and **MAY** are normative.

## Identity and configuration

- **PD-ID-001:** Every physical card instance MUST have one unique, immutable string instance ID.
- **PD-ID-002:** Multiple physical instances MAY share the same logical card key.
- **PD-ID-003:** Omitted IDs MUST be generated deterministically as `instance-1`, `instance-2`, and
  so on, skipping IDs already in the registry.
- **PD-CONFIG-001:** A card definition MUST provide a string logical-key function and MAY provide
  named classifiers returning one string or a list of strings.
- **PD-CONFIG-002:** Classifier values MUST be deduplicated, sorted by Unicode code-point order, and
  cached when an instance enters the registry.
- **PD-CONFIG-003:** An empty logical key, empty classifier name/value, invalid callback result, or
  duplicate instance ID MUST fail before state is created or changed.

## Immutable state and positions

- **PD-STATE-001:** Every successful operation MUST return a new state, increment the revision once,
  and append one audit event. Previous states MUST remain unchanged.
- **PD-STATE-002:** An instance MUST occupy exactly one concrete zone: active deck or drawn zone.
- **PD-STATE-003:** Failed operations MUST NOT change deck state, knowledge, revision, audit history,
  or random-source state.
- **PD-POS-001:** Card indices, offsets, and insertion gaps are zero-based. Probability draw numbers
  are one-based.
- **PD-POS-002:** An active deck of length `L` has card indices `0..L-1` and insertion gaps `0..L`.
  `fromBottom: 0` resolves to gap `L`.
- **PD-POS-003:** Move selections resolve against the pre-operation deck. After simultaneous removal,
  their destination resolves against the remaining deck.
- **PD-POS-004:** Bounds behavior defaults to `error`. `clamp` MUST report requested and applied
  values, the reference length, and whether clamping occurred.
- **PD-POS-005:** Shuffle ranges use a half-open interval `[startIndex, endIndexExclusive)`. Random
  placement ranges use inclusive insertion-gap endpoints.

## Knowledge and observations

- **PD-KNOW-001:** Concrete order and observer knowledge MUST be distinct. Access to privileged audit
  data MUST NOT implicitly update observer knowledge.
- **PD-KNOW-002:** Knowledge MUST be an exact normalized weighted collection of hypotheses.
- **PD-KNOW-003:** Within one hypothesis, every active or drawn location MUST be fixed to an instance
  or belong to exactly one uniform pool. A pool MUST contain equally many candidate IDs and locations,
  with a uniform bijection between them.
- **PD-KNOW-004:** Equivalent hypotheses MUST be merged and all weights MUST be reduced exact
  fractions whose total is `1/1`.
- **PD-KNOW-005:** Hidden random outcomes MUST transform knowledge across every possible outcome;
  revealed outcomes and observations MUST condition and renormalize it.
- **PD-KNOW-006:** An observation MAY identify an exact instance or assert that a structured target
  matches or does not match a concrete location.
- **PD-KNOW-007:** Observations inconsistent with concrete state MUST fail as impossible.
- **PD-KNOW-008:** An operation projected to exceed `maxHypotheses` MUST fail before random values are
  requested. The default maximum is 10,000.
- **PD-KNOW-009:** Implementations MUST NOT replace an unsupported or over-limit exact state with an
  approximation.

## Targets and probabilities

- **PD-TARGET-001:** Targets MUST support physical instance ID, logical card key, classifier equality,
  and non-empty nested `all`, `any`, and `not` expressions.
- **PD-TARGET-002:** Each physical instance contributes at most once to a target, even when multiple
  branches of a composite expression match it.
- **PD-PROB-001:** `next` means active index `0` in the current snapshot.
- **PD-PROB-002:** `atDraw(N)` means active index `N-1` in the current snapshot and does not implicitly
  condition on unobserved earlier draws.
- **PD-PROB-003:** `withinDraws(N)` means at least one matching instance in active indices `[0,N)`.
  `N=0` MUST return `0/1`.
- **PD-PROB-004:** `next` on an empty deck, exact draws outside `1..L`, and cumulative counts outside
  `0..L` MUST fail.
- **PD-PROB-005:** For one pool with `m` candidates, `t` matching candidates, and one queried pool
  location, exact-position probability is `t/m`.
- **PD-PROB-006:** For `s` queried locations in that pool, its no-hit probability is
  `C(m-t,s)/C(m,s)`. Independent pool no-hit factors multiply inside a hypothesis.
- **PD-PROB-007:** Hypothesis probabilities MUST combine by exact weighted sum.
- **PD-PROB-008:** Results MUST expose a reduced exact fraction, approximate decimal, percentage, and
  versioned structured explanation.
- **PD-PROB-009:** Explanations MUST distinguish deterministic hits/misses, pool factors, weighted
  hypotheses, and matching copies excluded because they are drawn or outside the query scope.

## Operations and visibility

- **PD-OP-001:** Creation preserves supplied order and begins with fully known positions.
- **PD-OP-002:** Shuffle MUST support the whole deck or a valid region and use unbiased Fisher-Yates
  sampling for concrete order.
- **PD-OP-003:** Insert MUST support new cards or registered drawn instances, exact/from-top/from-bottom
  gaps, and a uniformly selected gap in an inclusive region.
- **PD-OP-004:** Move MUST support unique pre-operation indices or active instance IDs.
- **PD-OP-005:** Multi-card insert and move operations MUST produce one contiguous batch. Preserved
  order is input order for new cards and current top-to-bottom order for moved cards.
- **PD-OP-006:** Random batch order MUST be a uniform permutation.
- **PD-OP-007:** Draw MUST remove one or more cards from the top into the drawn zone. Identity is
  revealed by default and MAY be hidden explicitly.
- **PD-VIS-001:** Shuffle permutations, random placement, and random batch order are hidden by default
  and MAY be revealed explicitly.
- **PD-VIS-002:** Requested operations are observer-visible. Hidden applied random resolutions appear
  only in the privileged audit projection.

## Randomness

- **PD-RNG-001:** Random operations MUST require an injected source and MUST NOT use ambient global
  randomness.
- **PD-RNG-002:** The built-in portable algorithm is `pcg32-v1`, using unsigned 64-bit state and stream
  values, with default stream `1`.
- **PD-RNG-003:** Bounded sampling MUST use rejection sampling without modulo bias.
- **PD-RNG-004:** Audit records MUST contain enough accepted/rejected words and resolved choices to
  verify and replay every random decision.

## Events, persistence, and replay

- **PD-EVENT-001:** Event sequence and revision numbers MUST be contiguous and begin with
  `deck.created` at revision zero.
- **PD-EVENT-002:** Deterministic core events MUST NOT contain wall-clock timestamps.
- **PD-EVENT-003:** Observer event projections MUST redact hidden random resolutions.
- **PD-SER-001:** Fractions and unsigned 64-bit values MUST serialize as base-10 strings.
- **PD-SER-002:** Snapshots and event streams MUST carry explicit schema identifiers and versions.
- **PD-SER-003:** Card callbacks are not serialized. Restoration MUST receive configuration and MUST
  reject recomputed logical/classifier metadata that differs from recorded metadata.
- **PD-REPLAY-001:** Replay MUST apply recorded resolutions without calling a random source.
- **PD-REPLAY-002:** Unknown versions, malformed envelopes, event gaps, or state divergence MUST fail
  with stable error codes.
- **PD-REPLAY-003:** Built-in random state MUST resume after replay. Continuing from a custom random
  source requires a caller-supplied replacement when its state is not serializable.

## Stable errors

V1 stable codes are `INVALID_CONFIG`, `INVALID_CARD_METADATA`, `DUPLICATE_INSTANCE_ID`,
`UNKNOWN_INSTANCE`, `INSTANCE_NOT_DRAWN`, `INVALID_TARGET`, `UNKNOWN_CLASSIFIER`, `INVALID_POSITION`,
`POSITION_OUT_OF_BOUNDS`, `INVALID_REGION`, `INVALID_COUNT`, `EMPTY_DECK`, `RANDOM_SOURCE_REQUIRED`,
`INVALID_RANDOM_VALUE`, `INFERENCE_LIMIT_EXCEEDED`, `IMPOSSIBLE_OBSERVATION`,
`INVALID_SERIALIZED_DATA`, `UNSUPPORTED_SCHEMA_VERSION`, `CARD_METADATA_MISMATCH`, and
`REPLAY_DIVERGENCE`.
